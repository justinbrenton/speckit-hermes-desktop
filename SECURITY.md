# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅                 |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security vulnerability in this project, please report it responsibly.

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to: **security@justinbrenton.com**

Include the following information:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact
- Any suggested mitigations

We will acknowledge receipt within 48 hours and provide a preliminary assessment within 5 business days. We will work with you to understand and resolve the issue promptly.

## Disclosure Policy

We follow responsible disclosure practices:
- We will not take legal action against researchers who report vulnerabilities in good faith
- We will coordinate disclosure timing with the reporter
- We will credit the reporter (if desired) in the security advisory

## Scope

This policy applies to the `speckit-hermes-desktop` repository and its released artifacts.
